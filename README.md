## 快照与更新

CCT 打开页面先显示完整的已核验快照，再读取主站保存的共享结果，不会在进入页面时自动逐地址扫描。点击「更新快照」推进共享任务，更新期间已有榜单仍可搜索、排序和导出。停止或关闭页面会保留已完成的共享进度；没有设置无人访问时的定时刷新。

「重新核验全网」是显式的完整扫描操作。所有历史候选地址的算力锁定在同一个规范区块哈希，区块、实现与精确整数总量核验通过后才作为完整报告。

GAS 区域默认显示独立的最新 LP 持仓快照，点击「快速更新 LP」后读取当前净持仓、排名、池子及同区块全退 QKI 估值。复用已知地址索引，只补充发现新增地址；每次更新都会重新读取全部候选地址的当前 `userLP`，合计必须精确等于 `totalUserLP`，失败或取消保留已有快照。净持仓占比的分母始终为同一区块的 `totalUserLP`。

快速模式可使用一个正常响应的固定公共节点，历史事件仅用于发现候选地址。它不更新历史买入、赎回、成本或累计盈亏。因为份额非负，遗漏正持仓地址会使 LP 总量对账失败；漏掉已全部退出的零持仓地址不影响当前持仓排名。

当前 LP 更新先读取已知地址的最新份额；如果其精确合计已经等于合约总 LP，就直接完成，无需等待历史事件扫描。只有出现份额差额时，才从最近的区块向前补查新增地址，且只读取新发现地址的份额。事件读取以最多 5,000 个区块为一段，遇到节点日志上限或密集买入退款核验时自动缩小区间。完整历史也使用较大的增量区间，继续保留双节点一致性、退款证据和最终总量核验。

赎回盈亏与自定义多地址清仓模拟直接显示，不需展开历史区。GAS 区域顶部提供当前 LP、赎回盈亏、多地址清仓和 CCT 产出燃烧的跳转入口。每个模拟器标明所用快照时间；展开「完整买入与赎回历史」可查看和更新完整历史报告。该更新仍需两个节点核对历史事件及买入退款；复用最新完整快照并分段补读，随后核对持仓变化地址。节点故障时保留旧历史结果和日期，不会用旧成本计算新快照盈亏。页面不会在首次打开时自动启动历史扫描，两种快照均无需钱包、付款或登录。

历史快照不是实时状态。公开节点故障、合约升级、区块重组或核验失败时，页面会明确提示，不把不完整的新数据当作完整结果。

燃烧包含主动燃烧与转账中实际销毁的 CCT；新增铸造包含挖矿、邀请奖励及旧铸币入口。累计参与地址是历史主动燃烧地址去重，不等于当前有正算力的地址数。统计通过链上事件回放与快照对账，缺失数据不会填为零。

打开页面先显示已保存结果，手动刷新才补读增量，不自动回扫历史。可选时间范围、查看逐日明细和导出精确 CSV。日终实数与产出／燃烧的假设模拟分开显示。

## QKI 盈亏与清仓口径

盈亏使用已核验的买入净投入、历史赎回到账和当前退出估值。买入余款退款证据不完整时，对应成本与盈亏保持未知；不会把买入毛额误当作完整净投入。

逐地址独立退出报价从同一池子开始计算，不能直接相加作为所有人同时退出的可兑现总收入。多地址清仓模拟按指定顺序逐笔更新池子，前一个地址的退出会影响后续地址的回款；支持额外到账折减、手动 Gas、清仓后整体数据和剩余持仓收益重算。

模拟仅在浏览器中计算，不发送赎回、燃烧、授权或其他链上交易。快照之后的池子变化和实际交易执行条件会影响真实结果。
