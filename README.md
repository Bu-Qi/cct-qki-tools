## 快照与更新

CCT 打开页面先显示完整的已核验快照，再读取主站保存的共享结果，不会在进入页面时自动逐地址扫描。点击「更新快照」推进共享任务，更新期间已有榜单仍可搜索、排序和导出。停止或关闭页面会保留已完成的共享进度；没有设置无人访问时的定时刷新。

「重新核验全网」是显式的完整扫描操作。所有历史候选地址的算力锁定在同一个规范区块哈希，区块、实现与精确整数总量核验通过后才作为完整报告。

QKI 区块先显示带区块和时间的已核验历史快照。点击「刷新项目」后才补读买入、赎回事件与同一区块的地址 LP；页面不会在首次打开时自动启动全项目扫描。净持仓占比使用累计获得 LP 减累计赎回 LP，并与 `userLP` 及 `totalUserLP` 对账。

历史快照不是实时状态。公开节点故障、合约升级、区块重组或核验失败时，页面会明确提示，不把不完整的新数据当作完整结果。

## QKI 盈亏与清仓口径

盈亏使用已核验的买入净投入、历史赎回到账和当前退出估值。买入余款退款证据不完整时，对应成本与盈亏保持未知；不会把买入毛额误当作完整净投入。

逐地址独立退出报价从同一池子开始计算，不能直接相加作为所有人同时退出的可兑现总收入。多地址清仓模拟按指定顺序逐笔更新池子，前一个地址的退出会影响后续地址的回款；支持额外到账折减、手动 Gas、清仓后整体数据和剩余持仓收益重算。

模拟仅在浏览器中计算，不发送赎回、燃烧、授权或其他链上交易。快照之后的池子变化和实际交易执行条件会影响真实结果。
